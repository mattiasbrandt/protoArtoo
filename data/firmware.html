Firmware

How do you put a new build on the droid without reaching for a cable?

Controller firmware

the program the droid runs

The controller's own code: drive, dome, sound, the radio and this web server. It arrives as one .bin the build produced, goes into the spare half of the flash, and only becomes the running firmware once the whole file has landed.

Keep the power on until the droid has restarted by itself. Cutting power part-way through, or refreshing this page, leaves half an image behind.

Web UI files

these pages, as one image

Every screen you are reading, packed into one filesystem image. It is a separate upload from the firmware above because the two change at different rates: a copy fix is a new web UI and the same controller code.

Keep the power on until the droid has restarted by itself. A part-written filesystem leaves no web UI at all: the droid still drives and the serial Console still answers, but nothing in a browser does.

Reboot

about ten seconds off the air

Start the controller again without cutting its power. Reach for it when a page stops answering and neither upload above is running; everything you have saved survives, and nothing is written or erased.

Refused while an upload is in flight, because a reboot part-way through one is exactly what leaves a half-written image behind.
