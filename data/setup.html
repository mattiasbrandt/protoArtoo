Utility arms

2 arms, one servo each

Tick the arms you have fitted, and say which servo is on each one. The type decides the widths the controller will drive that output between.

AUX outputs

3 spare lines

Spare outputs for whatever you have on them — a servo, a light, a smoke unit. Only one AUX line at a time can carry an LED strip.

RC Receiver Channels

Droid identity

what this droid answers to

The name is the droid's, not the browser's: it is stored on the controller, so a second computer or a cleared cache meets the same droid.

Restart

about ten seconds off the air

Some hardware answers only take effect when the controller starts again. Restarting cuts every output and reopens the page's connection; nothing you have saved is lost.
