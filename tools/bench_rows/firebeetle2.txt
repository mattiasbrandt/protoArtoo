# tools/bench_rows/firebeetle2.txt
#
# The replayable sheet for the FireBeetle 2 (ESP32-P4) Console bench runbook
# (#215), commands only -- everything #215 lists that the Console Client's
# scripted mode (#264) can express. Human-only steps (physical attach/detach,
# flashing, pressing heap from a browser) are `pause` directives; what a row
# is expected to answer stays on #215's own criterion, never written here
# (docs/console-client.md "Bench sheets and @row": there is no expect
# directive) -- a reviewer reads the transcript against the linked ticket.
#
# Plain requests to the droid's own routes are `http` steps, not pauses: they
# go to --http-base (or --http's base), and the answers a row keeps (`> FILE`)
# land in --run-dir. Board 1 has no network (its C6 is unflashable): run it
# with --no-http, and every http step prints [HTTP-SKIPPED] instead of the run
# being refused.
#
# Run with either adapter:
#   python3 tools/console_client.py --port /dev/ttyACM0 --http-base http://<host> \
#     --run-dir tasks/bench-run-p4 --script tools/bench_rows/firebeetle2.txt
#   python3 tools/console_client.py --http http://<host> --run-dir tasks/bench-run-p4 \
#     --script tools/bench_rows/firebeetle2.txt
#   python3 tools/console_client.py --port /dev/ttyACM0 --no-http \
#     --script tools/bench_rows/firebeetle2.txt                       (board 1)
#
# Select rows (by name only, e.g. "detach-replug" -- not the ticket number):
#   --rows detach-replug,tab-completion   (explicit order, not file order)
#   --skip-manual                         (every row with no `pause` -- agent-runnable)
